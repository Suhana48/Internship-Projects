## Task 01 – Command-Line Calculator

A Java-based command-line calculator that performs basic arithmetic operations based on user input.

### Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Input validation for invalid numbers
- Division by zero handling

### Technologies Used

- Java
- JDK
- IntelliJ IDEA
